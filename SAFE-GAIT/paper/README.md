# ACM research manuscript source

Compile in a LaTeX environment with the ACM `acmart` package:

```bash
latexmk -pdf -interaction=nonstopmode -halt-on-error main.tex
```

This is a **draft scaffold**, not a verified camera-ready artifact. The full bibliography must be completed and verified; some BibTeX fields are explicitly placeholders. No PDF compilation was performed in this phase. Do not delete the data-provenance limitation or treat historical FoG-STAR subset results as full-v3 validation. Figures and new full-v3 results are intentionally absent until they can be generated reproducibly.
